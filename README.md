# WinDirStat in Italiano per Windows

**WinDirStat in italiano per Windows** è uno strumento gratuito e open source per **analizzare lo spazio su disco**, trovare file di grandi dimensioni e capire rapidamente cosa sta occupando lo spazio di archiviazione del computer.

Questo progetto è pensato per gli utenti italiani che vogliono utilizzare WinDirStat su Windows con una versione localizzata in italiano, mantenendo le funzionalità del progetto originale.

## Che cos'è WinDirStat?

WinDirStat è un **analizzatore dello spazio su disco per Windows** che permette di visualizzare come viene utilizzato lo spazio di archiviazione del computer.

Il programma analizza dischi e cartelle e presenta i risultati attraverso un elenco di file e una visualizzazione grafica Treemap.

La visualizzazione permette di individuare rapidamente i file e le cartelle che occupano più spazio.

Se il tuo **disco è pieno** e non sai perché, WinDirStat può aiutarti a trovare file di grandi dimensioni, cartelle molto pesanti e altri dati che stanno occupando lo spazio disponibile.

## Perché utilizzare un analizzatore del disco?

Nel corso del tempo, download, video, immagini, file temporanei, backup e programmi possono occupare una quantità significativa di spazio.

Windows fornisce alcune informazioni sull'archiviazione, ma un analizzatore del disco permette di ottenere una visualizzazione molto più dettagliata del contenuto del disco.

WinDirStat organizza i dati in modo visivo per permetterti di capire rapidamente dove viene utilizzato lo spazio.

## Quali sono le principali funzionalità?

* Analisi dello spazio utilizzato su dischi e cartelle
* Visualizzazione grafica dello spazio su disco
* Treemap per individuare i file più grandi
* Elenco di file e cartelle
* Ordinamento per dimensione e tipo di file
* Visualizzazione per estensione
* Ricerca dei file
* Filtri per analizzare i contenuti
* Individuazione dei file duplicati
* Informazioni dettagliate sulle dimensioni dei file
* Integrazione con Esplora file di Windows
* Strumenti di pulizia
* Supporto per volumi NTFS
* Versione portatile disponibile in alcuni release
* Compatibilità con Windows 10 e Windows 11

2. Installa WinDirStat oppure utilizza la versione portatile quando disponibile.
3. Avvia il programma.
4. Seleziona il disco o la cartella che vuoi analizzare.
5. Attendi il completamento dell'analisi.
6. Utilizza l'elenco dei file e la visualizzazione Treemap per individuare cosa occupa più spazio.

Al termine dell'analisi puoi identificare rapidamente i file e le cartelle più grandi presenti sul computer.

## Come trovare i file più grandi?

Dopo aver completato l'analisi, controlla le dimensioni dei file e delle cartelle visualizzate da WinDirStat.

La Treemap rende questa operazione più semplice: maggiore è lo spazio occupato da un file o da una cartella, maggiore sarà la relativa area nella visualizzazione.

Puoi così individuare rapidamente video, file di installazione, backup, download o altri dati che occupano molto spazio.

Prima di eliminare qualsiasi file, assicurati che non sia necessario a Windows o a un altro programma.

## Come liberare spazio sul disco?

Prima utilizza WinDirStat per capire quali file e cartelle occupano più spazio.

Dopo aver individuato i dati che non ti servono più, puoi ad esempio:

* Eliminare file temporanei
* Rimuovere vecchi download
* Eliminare file di grandi dimensioni non più necessari
* Spostare i file personali su un altro disco
* Archiviare documenti e file multimediali
* Disinstallare i programmi che non utilizzi più

Fai attenzione ai file di sistema e ai file di cui non conosci la funzione.
